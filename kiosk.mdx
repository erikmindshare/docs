# Kiosk

Kiosk mode starts the survey again after each person. It hides the answers of the last person.

<Note>
Interview Mode is in development. It is not available in installed AutoSurvey orgs yet. This page tells you what the interview does when it is available.
</Note>

<Warning>
This feature is not available yet. The interview does not ask this question in any org today. The text above tells you what the topic is for. This page shows what the interview has ready for when the feature is released.
</Warning>

## Status

- AutoSurvey does not register a **kiosk** feature in this release. The interview treats a topic with an unknown feature as not installed, and it never asks a topic that is not installed. The topic also does not show in the list of all topics.
- If a choice for this topic reaches the change list, it does not change the survey. It goes to the **Set up next** list as a card that says: "You chose this in the interview. This feature is not in AutoSurvey yet. The choice is kept for when it ships."
- Kiosk mode is not in AutoSurvey yet. To let one person answer more than once, see [Retakes](/retakes).

## The question and the choices

When the feature is released, the interview asks: **Run the survey on a shared tablet?** The interview is to ask it when your brief mentions a tablet, a front desk or a booth.

| Choice | What you see |
| --- | --- |
| **Yes, run it on a shared device** (recommended) | The survey resets after each answer. Retakes are on. |
| **No** | The survey runs as a normal link. |
