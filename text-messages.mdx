# Text messages

People with a mobile number get the link by text message. They answer on the phone.

<Note>
Interview Mode is in development. It is not available in installed AutoSurvey orgs yet. This page tells you what the interview does when it is available.
</Note>

## When the interview asks

The interview asks this question when your brief says that people are on site, in the field or on mobile, or that you text them.

The question is: **Send the link by text message too?** The screen selects the recommended choice first. You can click a different choice.

## The choices

| Choice | What you see | What AutoSurvey changes |
| --- | --- | --- |
| **No, use email** (recommended) | AutoSurvey sends the invitation by email. | Nothing. |
| **Yes, send by text message** | AutoSurvey sends the invitation by text. You set up the sender after Create. | Keeps the value on the draft. After Create, the card **Text message invitations** shows. |

The interview does not set up text messages and does not send a text.

## The Set up next card

| Card part | Value |
| --- | --- |
| **What and why** | You chose to send invitations by text message. An admin must set up text messaging first. |
| **Who** | An admin |
| **Link** | **Open Text Messaging setup**. It opens AutoSurvey Setup at the text messaging section. It does not take a survey. |
| **Example flows** | AutoSurvey_Text_Invitation and AutoSurvey_Text_Sender |
| **Done** | The card has no done check. It stays in the list until you dismiss it. |

## Limits

- AutoSurvey does not set up the text sender for you. The example flows ship as examples. An admin sets them up.
