---
title: "Fill in what you know"
description: "Use a Flow action to fill in survey answers that you already have, such as a region or a name, before the person sees the survey."
---

You already know the region or the name of the person. The person does not need to type it again. In a Screen
Flow that shows the survey, the action **AutoSurvey: Prefill Answers** writes the values as draft
answers. The person sees each value and can change it.

## Add the action to your Flow

1. Add the action **AutoSurvey: Start Survey**. It returns the run token and the resume secret.
2. After it, and before the survey screen, add **AutoSurvey: Prefill Answers**.
3. Fill in the inputs:

   | Input | Value |
   | --- | --- |
   | **Run Token (Submission Key)** | The run token from **AutoSurvey: Start Survey**. |
   | **Resume Secret** | The resume secret from **AutoSurvey: Start Survey**. |
   | **Question API Names** | The API names of the questions. |
   | **Values** | One value for each question, in the same order. |

4. Read the outputs **Success**, **Prefilled Count**, **Skipped Existing Count** and **Error Message**.

## Limits

- The action fills text, number, true/false, single-choice and NPS questions. For a choice question, give
  the option value.
- It refuses matrix, ranking, file, signature, multi-select, date, time, star and slider questions.
- One call fills 50 questions at most.
- It does not change a question that has a saved answer.
- If one value is not valid, the action writes nothing.
- For a Flow on a public site, give the guest profile access to the action. **AutoSurvey Guest Access**
  does not contain it.

<Warning>
The respondent sees each value. In a Flow for guests, do not use data that the respondent must not see.
</Warning>
