# Review before Submit

People see all their answers on one page. They can change an answer before they submit.

<Note>
Interview Mode is in development. It is not available in installed AutoSurvey orgs yet. This page tells you what the interview does when it is available.
</Note>

<Warning>
This feature is not available yet. The interview does not ask this question in any org today. The text above tells you what the topic is for. This page shows what the interview has ready for when the feature is released.
</Warning>

## Status

- AutoSurvey does not register a **review-before-submit** feature in this release. The interview treats a topic with an unknown feature as not installed, and it never asks a topic that is not installed. The topic also does not show in the list of all topics.
- If a choice for this topic reaches the change list, it does not change the survey. It goes to the **Set up next** list as a card that says: "You chose this in the interview. This feature is not in AutoSurvey yet. The choice is kept for when it ships."
- A review page is not in AutoSurvey yet.

## The question and the choices

When the feature is released, the interview asks: **Show a review page before Submit?** The interview is to ask it when your brief describes a long application or a request.

| Choice | What you see |
| --- | --- |
| **Yes, show a review page** (recommended) | People see all their answers before they submit. |
| **No** | The survey submits after the last question. |
