# Document request

A document request sends one person a checklist of files to upload and forms to sign. It has a secure link and a due date. You review each file. It is separate from the survey.

<Note>
Interview Mode is in development. It is not available in installed AutoSurvey orgs yet. This page tells you what the interview does when it is available.
</Note>

## Before you start

This topic belongs to the feature **Participant Request Center**. When the feature is off, the interview shows the topic as turned off, and the Set up next card shows the state **Feature is off**.

## When the interview asks

The interview asks this question when your brief asks for files, proof, an ID or signatures.

The question is: **Do you also need files or signed forms from each person?** The screen selects the recommended choice first. You can click a different choice.

## The choices

| Choice | What you see | What AutoSurvey changes |
| --- | --- | --- |
| **Yes, ask for documents** (recommended) | A Set up next card opens Document requests with this survey picked. | No setting changes. After Create, the card **Ask for a document** shows. |
| **No** | The survey asks for no files. | Nothing. |

For one file only, you can add a file upload question to the survey instead.

## The Set up next card

The card shows when you chose **Yes**. It also shows when the survey has a file upload question.

| Card part | Value |
| --- | --- |
| **What and why** | This survey asks for a document. A document request template lets people send the file safely. |
| **Who** | An admin |
| **Link** | **Open the Template Builder**. It opens the Document Request Template Builder. It does not take the survey. |
| **Example flow** | AutoSurvey_Document_Request_Text |
| **Done** | The card has no done check. It stays in the list until you dismiss it. |

## Limits

- The Template Builder opens with no survey picked.
- The interview does not make a document request template.
