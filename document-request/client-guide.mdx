This page is for the person who receives a link, for example Jordan Rivera at Harbor Community Health. Staff can share this page with a client.

## Open the link

1. Open the link in the email from the office. It works on a phone or a computer.
2. The page shows "Your requests" and "To see your requests, enter the code we send to the email address on file."
3. Select **Send me a code**. The system sends a 6-digit code to the email address on file. The code works for 10 minutes.
4. Type the code in **6-digit code** and select **Check code**. If you need a new code, select **Send a new code**.
5. The page shows the name of the program record, "Hello" and your first name, and a list of items.

A forwarded link alone shows no name and no request. The page shows the list only after the code is right.

Your session lasts 15 minutes after the code. When you work on the page, the session continues, up to 2 hours. Before the session ends, the page says "You will be signed out in" and a number of seconds. Select **Keep me signed in** to continue. When you are done, select **I'm finished**.

Each item shows one of these states: **To do**, **Continue**, **Received, in review**, **Needs a replacement**, **Done**, **No longer needed**. Select **Open** to start an item.

If the link does not work, the page says "This link is no longer valid." Then it says: "Ask your case manager for a new one." A link can fail because it is wrong, expired, replaced by a newer link, or revoked. If you reload the page and the link is gone from the address, the page says "This page needs your link." Open the link from your email again.

## Send a photo or a file

1. Open the item.
2. Select **Take a photo or choose a file**. You can use the camera, or choose an image or a PDF.
3. The page checks the picture on your device. The page shows **Looks readable.** or a message, for example:
   - "This looks like a blank page"
   - "Too dark to read"
   - "Too bright or glare on the page"
   - "That one looks blurry"
   - "A corner is cut off"

   Each message has tips.
4. If the picture is good, select **Send**. Or choose **Choose a different one**.
5. If the check fails, select **Retake**. What happens next depends on the item:
   - For some items, you can select **Send anyway and let staff decide** at once.
   - For most items, you try again. After the set number of failed checks, you can select **Send for staff review**. The page says how many tries are left.
   - For some items, the page sends only a picture that passes the check. Then the page says "This item needs a clear photo. Take the photo again, then send it."
6. The page says that the page is sent. To send one more page, select **Add another page**. When you have sent all pages, select **I am done with this item**.

The file must be a JPG, PNG or PDF. The size limit is 3.5 MB or less. The office can set a lower limit for an item. If you tap Send two times, only one copy goes.

If the page says "This file is too large. Choose a file smaller than" a number of MB, or "That file is empty. Choose a different file.", choose a different file.

## Acknowledgment

1. Type your full name.
2. Tick the box.
3. Sign below if you want. This step is optional.
4. Select **Send**.

The system usually accepts this item immediately. The office can set the item to staff review.

## Forms

A form item opens the questions on the same page. "Your answers save each time you go to the next page. You can come back to this link and continue from there."

<Warning>
Do not leave a one-page form half done. A one-page form can lose answers if you reload the page.
</Warning>

After you send, the page says "Thanks. Your answers are in."

- If staff must review, the item says "Received, in review".
- If not, it says "Done".

If a form is not ready, the page says "This item is in development. It cannot be opened yet."

If you open the same item in a second tab, the page says "This item is waiting for review." or "This item is closed. It cannot be changed."

## Sign a document

1. **Read the document.**
2. Type your full name (up to 120 characters).
3. Sign. Draw your signature, or type it.
4. Read the text about electronic signing.
5. Tick "I agree to sign this document electronically."
6. Select **Sign and send**.

### Sign for someone else

Some documents let you sign for another person. If so, you see "I am signing for someone else".

1. Tick the box.
2. Choose "Parent or guardian" or "Authorized representative".
3. Type your **own** full name (the person who signs).
4. Confirm the statement "I confirm that I have the authority to sign this document for" followed by the name of the person you sign for.

The page says: "The office does not check your identity or your authority when you sign here." The certificate shows "Identity and authority" with the value "Not verified".

### After you sign

The page goes back to the list and says "Thanks. Your signature is in." The system then makes the PDF. This can take a short time. When you open the item again, the page has a **Check again** button while it waits. The page then shows the Document ID, what you signed, what you entered, and a certificate.

If a document has a character that the PDF cannot print, the page tells you that you cannot sign it online. Nothing is wrong with your entry. Ask the office for a paper copy to sign. Staff can upload the signed paper copy for you.

## If staff send an item back

The item says "Staff asked for a new one:" and the reason. For a signed document, it says "Please sign again:" and the reason. Open the item and send a new one.

## When you are done

When nothing waits for you, the page says "Nothing is waiting for you right now." The items that are done are under "Done" and the number of items.

The page footer says: "In development."

## Using a staff device

Staff can open your request on their tablet. Then you also enter the code from your email. The page shows only that one request. The session ends 30 minutes after staff start it. When you finish, tap **I'm finished**. The page says "You are finished. To see your requests again, ask for a new code."
