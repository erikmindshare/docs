This page takes you from an empty org to a sent request. The example sends an intake request to the fictional client Jordan Rivera at Harbor Community Health.

## Before you start

- An admin turned on the card **Participant Request Center** in **Setup**, **Features**. See [Admin Setup](/document-request/admin-setup#turn-on-the-feature).
- You have the `Participant_Request_Center_User` permission set. See [Admin Setup](/document-request/admin-setup#permission-sets).
- To create templates, you have the `Document_Request_Author` permission set. To make a template Active, you also have the `Document_Request_Template_Publisher` permission set.
- The Contact page shows the **Participant Request Center** panel. See [The Contact page](/document-request/admin-setup#the-contact-page).

## Open the app

Open the App Launcher. Search for **Document Requests**. Open the app **AutoSurvey - Document Requests**. The app has five tabs:

| Tab | Use it to |
| --- | --- |
| Contacts | Open a client. Issue the link and create a request on the panel. |
| Document Review Queue | See the items that wait for your review. |
| Document Requests | List all requests that you can see, and open one to review it. |
| Document Request Templates | See the template records. |
| Template Builder | Create, check and activate templates. |

If the app is not in the App Launcher, open the tab by its name in the App Launcher search instead.

## Create a template

<Steps>
  <Step title="Start a template">
    Open the **Template Builder** tab. Click **New template**. Choose **Start blank**. Enter a name, for example "Family Support Intake". Click **Make a blank Draft**.
  </Step>
  <Step title="Fill in the fields">
    Set **Due after (days)** to 14. Set **Code** to `DR_INTAKE`. The panel uses the Active template with this code. If no Active template has this code, the panel uses the only Active template.
  </Step>
  <Step title="Save">
    Click **Save**.
  </Step>
</Steps>

## Add the items

<Steps>
  <Step title="Add an item">
    Under **Add an item**, click **File upload**.
  </Step>
  <Step title="Describe the item">
    In **Label the client sees**, enter "Photo ID". Turn on **Required**. Set **Review** to Staff review.
  </Step>
  <Step title="Save and repeat">
    Click **Save**. Add the next item the same way. Example: an **Acknowledgment** item "Consent to share information".
  </Step>
</Steps>

For each field, see [Template item fields](/document-request/admin-setup#template-item-fields).

## Make the template Active

Click **Review readiness**. Fix each problem that the check shows. Click **Activate**. Only an Active template can be sent. An Active template cannot change. To change it, use **Copy to draft**.

## Send the first request

<Steps>
  <Step title="Open the client">
    Open the **Contacts** tab. Open Jordan Rivera.
  </Step>
  <Step title="Start the request">
    In the **Participant Request Center** panel, click **New request for this enrollment**.
  </Step>
  <Step title="Add it to the request center">
    Keep **Add to the participant's request center** on. If the client has no active link, the system issues a link to the client's email address.
  </Step>
  <Step title="Create">
    Click **Create request**. The panel shows "Request created." The request uses the template from the step above. Its due date is the template **Due after (days)** from today.
  </Step>
</Steps>

<Note>
The system sends one email with the link. When live email is off (the default), the system writes a dry-run log and sends no email. Then use **Copy link** on the panel and give the link to the client in another way.
</Note>

## Follow the request

- Open the request from the **Document Requests** tab. The record page shows each item, its attempts and the event trail.
- Open the **Document Review Queue** tab to see the items that wait for review.
- To review an item, see [Review an item](/document-request/staff-guide#review-an-item).
