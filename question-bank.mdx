title: "Standard questions"
description: "Keep a library of locked standard questions for the org. Authors insert them into any survey, and one trend shows the answers across all surveys."
---

The question bank holds wordings that your team already approved. This interview does not read the
bank, so the AI writes its own wordings.

When each author writes "How satisfied are you?" in a different way, you cannot compare the answers
of two surveys. With **Standard questions**, an admin writes the question one time in the **Question
Library**. Authors insert it into a survey. The wording and the scale stay the same, so one trend
shows the answers of all surveys that use the question.

## Before you start

- The card **Standard questions** in **Setup**, **Optional Capabilities** is on by default. An admin
  can turn it off.
- The switch gives the permission set **AutoSurvey Standard Questions** to the AutoSurvey admins.
- To see answers in the library, a user also needs raw response access.

## Add a standard question

1. Open the **Setup** tab and open **Question Library**. The entry shows only while the feature is on.
2. Click **New standard question**.
3. Fill in the fields:

   | Field | Meaning |
   | --- | --- |
   | **Code** | A short code for the question. 40 characters at most. You cannot change it later. |
   | **Topic** | A group for the question. 80 characters at most. |
   | **Question** | The text that the respondent reads. |
   | **Help** | The help text below the question. |
   | **Display type** | How the question shows. |
   | **Scale from** and **Scale to** | The lowest and the highest value of a scale question. |
   | **Options, one per line: value \| label \| score** | The answer options of a choice question. |

4. Click **Save draft**.
5. Select the question and click **Publish version 1**. Authors can insert only a published question.

## Change or retire a question

- Click **Edit** to make a new draft of a published question. Publish the new version.
- AutoSurvey does not publish a draft that changes the scale or the scores. Thus a trend does not
  mix two scales. Make a new standard question instead.
- Click **Retire** to stop new use of the question.

## Insert a standard question into a survey

1. Open the survey and open the **Questions** tab.
2. Below the questions of a section, click **Insert a standard question…**. The button shows only when
   the library has a published question.
3. In **Search by code or wording**, find the question and click it.

## See the answers

Select a question in the **Question Library**. The page shows the answers from all surveys and the
**Trend over time**. Only questions that stay linked to the library count. Without raw response
access, the page says "You need the Raw Response Access permission to see the answers."
