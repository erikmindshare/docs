---
title: "Languages"
description: "Offer one survey in more than one language. Add a language, check the AI translation if you want to, and choose how AutoSurvey translates text answers."
---

Languages let people answer in their own language. AutoSurvey translates the survey. You can check each translation. People who use one language never see the choice.

Your respondents do not all read the same language. With **Multi-language surveys**, you write the
survey one time. AutoSurvey translates the survey with your AI provider. You can review each
translation before you release it.

## Before you start

- An admin turns on the feature. Open the **Setup** tab, open **Optional Capabilities**, and turn on
  the card **Multi-language surveys**. The feature is off until an admin turns it on.
- The switch gives the permission set **AutoSurvey Multi-language** to the AutoSurvey admins.
- AI is set up for the org. See [Setup Home](/admin/setup#ai-models).

## Add a language

1. Open the survey.
2. Open the **Settings** tab and find the card **Languages**.
3. Check **Written in**. This is the language of your questions. Reports use it. You cannot change
   it after the first release.
4. Select a language in the list and click **Add language**. AutoSurvey translates the survey.
   While it works, the card shows "A translation runs…".

Each language shows as a row with its status and its counts. **Remove** takes a language off the
survey. **Add again** puts it back.

After you change questions, click **Translate changed text**. AutoSurvey translates only the text
that changed.

## Review the translations

You can review each translation before you release it. A review is not necessary, with one exception:
legal text must be reviewed. If legal text is not reviewed, the release dialog shows it and holds the
release. Review the text, or click **Confirm legal text** in the dialog.

To review the translations:

1. Open the **Questions** tab, select **Preview**, and choose the language in **Language**.
2. Open the translations and select **Show only the text to review**.
3. Read each text. To correct one, edit it and click **Save**. Click **Accept** on a suggested text.
   Respondents do not see a suggested text before you accept it.
4. Click **Mark as reviewed** on a text that you checked. **Mark all as reviewed** marks all texts except legal
   text. Mark each legal text itself.

## Other settings on the card

| Setting | What it does |
| --- | --- |
| **Default language** | The language that a respondent gets when no other rule gives one. |
| **Languages that the team reads** | A text answer in one of these languages gets no translation. |
| **Words to keep** | Words that a translation keeps as they are, for example brand names. Put one on each line, or put commas between them. Click **Save words**. |

## Edit translations in a sheet or a file

- A survey with a Google Sheet shows **Sync now**. The **Translations** tab of the sheet has each text
  of the survey. Change a translation there. **Sync now** imports your changes and writes new text to
  the tab.
- A survey with no Google Sheet shows **Export CSV** and **Import CSV**. Export the texts, change a
  translation in the file, then import the file. AutoSurvey does not import a row that has a problem.

## Translate text answers

Two switches must be on:

1. An admin turns on the card **AI reads answers** in **Setup**, **Optional Capabilities**. It is off by
   default. While it is off, AutoSurvey translates no answer.
2. On the card **Languages**, turn on **Translate text answers**. It is off by default.

When the two switches are on, AutoSurvey sends free-text answers to your AI provider for translation.

- AutoSurvey translates new answers one time each hour. An answer can wait up to 60 minutes.
- Only an AutoSurvey admin or a support user can change this setting.
- **Put translations in the reporting record** writes each translation to the reporting record of
  the survey, in place of the original text.
- **Translate the earlier answers** sends the answers that came in before you turned the setting on.
