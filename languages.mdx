# Languages

AutoSurvey translates the questions into the languages that you pick. You check each translation before you publish. People then choose their language.

<Note>
Interview Mode is in development. It is not available in installed AutoSurvey orgs yet. This page tells you what the interview does when it is available.
</Note>

## Before you start

This topic belongs to the feature **Multi-language**. It is off by default. An admin turns it on in AutoSurvey Setup. When the feature is off, the interview shows the topic as turned off, and the Set up next card shows the state **Feature is off**.

## When the interview asks

The interview asks this question when your brief names countries, says "international", or is not in English.

The question is: **Offer the survey in more languages?** The screen selects the recommended choice first. You can click a different choice.

## The choices

| Choice | What you see | What AutoSurvey changes |
| --- | --- | --- |
| **Yes, add the languages I name** (recommended) | AutoSurvey adds the languages. People pick their language at the start. | No setting changes. After Create, the card **Add the languages** shows. |
| **No, one language** | The survey stays in one language. | Nothing. |

The AI can also read the languages in your brief at **Finish** and propose them as a change card. The interview keeps this value on the draft only. It does not change a survey setting. After Create, the value shows the Set up next card below. You do the setup there.

## The Set up next card

| Card part | Value |
| --- | --- |
| **What and why** | You chose more languages. Add each language to this survey, then check the translations. |
| **Who** | You, or an admin |
| **Link** | **Open the survey settings**. It opens the survey workspace with this survey. |
| **Done** | When the survey has at least one added language. |

## Change it later

Open the survey **Settings** tab, card **Languages**, and click **Add language**. See [Survey settings](/admin/survey-settings).

## Limits

- The interview does not add a language and does not translate. You add each language on the Languages card.
