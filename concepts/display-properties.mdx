**Display Properties** is an optional per-question column in the Questions sheet. What it accepts
depends on the question's [Display Type](/concepts/display-types). Leave it blank for the default.

<Tip>
  You don't have to hand-write this. The AutoSurvey sidebar in Google Sheets has a **Display
  Properties Builder**: select a question row and it shows the right fields for that question's
  type, with the default spelled out on each one, and writes the value for you.
</Tip>

## Two ways to write it

Either a JSON object, or semicolon-separated tokens. These are equivalent:

```json
{"maxRating": 10, "allowHalf": true}
```

```text
maxRating=10; allowHalf
```

<Warning>
  In token syntax, `multiSelect`, `subField`, `allowHalf`, `multiple`, `groupFields` must be written as a **bare word**.
  Writing `multiSelect=true` stores the *text* "true", which is not the same as the value
  `true`, and the setting is silently ignored. In JSON, write a real boolean.
</Warning>

## Layout

_Applies to every question type._

| Key | What it does | Values | If you leave it blank |
| --- | --- | --- | --- |
| `width` | How wide the answer box is. Narrower boxes suit short answers like a postcode. Choose Custom to set an exact width in pixels. | `narrow` · `medium` · `wide` · `full` | set in Design |
| `lines` | How tall the answer box is when the page opens. Respondents can still drag it larger. _(`LongText` · `Text Area` only)_ | A number (min 1, max 50) | set in Design |
| `subField` | Tuck this question under the one before it — no number of its own, indented, with a lighter label. For a follow-up that belongs to another question rather than standing beside it. | `true` / `false` | stands on its own |

## Format

_Applies to `Date` · `DateTime`._

| Key | What it does | Values | If you leave it blank |
| --- | --- | --- | --- |
| `dateStyle` | How the date is written — Short is numeric (04/08/2026), Long spells the month out. | `short` · `medium` · `long` | the site locale |
| `timeStyle` | How the time half is written on a Date/Time question. _(`DateTime` only)_ | `short` · `medium` | the site locale |

## Options

_Applies to Choice questions._

| Key | What it does | Values | If you leave it blank |
| --- | --- | --- | --- |
| `orientation` | Stack the options vertically, lay them out in a row, or let the survey decide from how many there are. | `Auto` · `Vertical` · `Horizontal` | automatic |
| `optionStyle` | Draw each option as a tappable card, or as a plain radio/checkbox with no box. | `card` · `plain` | set in Design |
| `optionFill` | Whether an option card is filled solid or tinted translucent. | `solid` · `translucent` | set in Design |
| `contentAlign` | Align the option text left, centred, or centred across the full width. | `left` · `center` · `center-full` | set in Design |

<Warning>
  `optionFill` has no effect when `optionStyle` is `plain` — Plain options have no card to fill.
</Warning>

## Grid

_Applies to `Matrix`._

| Key | What it does | Values | If you leave it blank |
| --- | --- | --- | --- |
| `multiSelect` | Turn each grid row into checkboxes so a respondent can tick more than one column. Off, a row is radio buttons and takes exactly one answer. | `true` / `false` | one answer per row |
| `shape` | Draw each grid cell as a radio button or as a star. | _(blank)_ · `star` | radio buttons |

## Rating

_Applies to `Star`._

| Key | What it does | Values | If you leave it blank |
| --- | --- | --- | --- |
| `maxRating` | How many stars the scale runs to. | A number (min 1, max 10) | 5 stars |
| `allowHalf` | Let respondents pick a half star (3½ out of 5). | `true` / `false` | whole stars only |

## Upload

_Applies to `FileUpload`._

| Key | What it does | Values | If you leave it blank |
| --- | --- | --- | --- |
| `multiple` | Let the respondent attach more than one file. | `true` / `false` | one file only |
| `maxSizeMb` | Reject an attachment bigger than this. | A number (min 1, max 100) | the org limit |
| `maxFiles` | How many files one respondent may attach. Only applies when multiple files are allowed. | A number (min 1, max 25) | one file |
| `accept` | Comma-separated extensions or MIME types, e.g. .pdf,.png. Leave blank to accept anything. | Text | any file type |

<Warning>
  `maxFiles` only applies when `multiple` (**Allow multiple files**) is on. With it off, the value is ignored.
</Warning>

<Warning>
  **`maxFiles` is checked when the file is saved, not when it is picked.** The upload control does not stop a respondent selecting more files than you allow — the extras are rejected on upload. If you set `maxFiles`, say so in the question's help text so nobody chooses files they will lose.
</Warning>

## Consent

_Applies to `Consent`._

| Key | What it does | Values | If you leave it blank |
| --- | --- | --- | --- |
| `termsUrl` | Web address of the terms being agreed to. Must start with http:// or https://. | An `http://` or `https://` address | no link |
| `termsLabel` | The clickable words for the terms link. | Text | the default wording |
