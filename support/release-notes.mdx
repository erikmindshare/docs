# Release Notes

AutoSurvey is in private preview. It is not on the Salesforce AppExchange yet, so there is no
public version history to publish.

## What you are running

Your org runs one specific package build. To read which one:

1. Open **Setup**.
2. Go to **Installed Packages**.
3. Read the version number beside **AutoSurvey**.

If someone set up a trial org for you, that build is the one they installed.

## What changes, and when you hear about it

During the private preview, the person who set up your org tells you directly when a change
affects you. Reply to the email that carried your login and ask what changed.

When the AppExchange listing goes live, this page carries a versioned changelog, with one entry per
released package version.
