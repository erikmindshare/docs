Every error AutoSurvey can show you — **63** of them — with the check that produced it.
For what to do about the common ones, start at [Troubleshooting](/support/troubleshooting).

<Note>
  **Blocking** stops the import until you fix it. **Advisory** lets the import through and tells
  you something will not behave the way you probably intended. **Info** is a suggestion the
  sidebar can usually apply for you.
</Note>
