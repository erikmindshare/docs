---
title: "Retakes"
description: "Let one person answer the same invitation again, for example after each visit. Retakes are off until you turn them on."
---

Some surveys are for one answer from each person. Other surveys are for an answer after each visit,
class or order. **Allow Retakes** controls this for an invitation link.

| Retakes | What the person sees after a first answer |
| --- | --- |
| On | The person opens the same invitation link and answers again. |
| Off | The link opens with the message "This invitation has already been completed. Retakes are not enabled for this campaign." If the person submits from a page that is still open, the message is "This invitation has already been completed. Retakes are not enabled." |

Retakes are off by default.

## Turn on retakes for a campaign

1. Open the Campaign record.
2. In the panel **Campaign Distribution**, find the row **Allow retakes**.
3. Turn on **Allow invitation retakes**.

The row then says **Retakes allowed**. When the switch is off, the row says **One answer per
invitation**.

## Which setting applies

The checkbox **Allow Retakes** is on three objects: the Campaign, the form and the survey. AutoSurvey
reads one of them for each invitation:

1. An invitation from a campaign uses the campaign.
2. An invitation with no campaign uses the form.
3. An invitation with no campaign and no form uses the survey.

Retakes apply to invitations only. The public link does not read this setting.
